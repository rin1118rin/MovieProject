# 映画予約管理システム 画面イメージ

画面設計書.xlsxの画面一覧・画面遷移図に合わせたHTML/CSS一式です。
ZIPを展開し、index.htmlを開いてください。管理者側はadmin-login.html、全画面はscreen-list.htmlから確認できます。
画面一覧の25種類＋閲覧用の画面一覧1ページ＋共通部品4ファイルです。

## 共通ファイル
header.html / footer.html：ユーザー用
admin-header.html / admin-footer.html：管理者用
style.css：全画面共通のスタイル
iframeで読み込むため、JavaScript・PHP・サーバーは不要です。

## 設計書内の表記差への対応
画面一覧を優先して、SCHD102を変更、SCHD103を登録としています（遷移図では逆）。
エラーページのIDは画面一覧のERRO001です。
分析一覧への矢印は遷移図のリンク名が上映スケジュールになっていますが、遷移先に合わせて「分析一覧」としています。
イベント処理シートには得点管理システム由来の項目が残っているため、映画予約の画面一覧・遷移図を基準にしています。
ロゴ表記は設計書内の画面イメージに合わせてO-HARAFILMとしています。

## 宣伝画像
images/banner1.jpg～banner3.jpgを配置するとトップ上部に表示されます。画像は同梱していません。
画像がない場合は背景色が表示されます。横スクロール・矢印・作品名リンクで切り替えできます。

## 実装範囲
画面設計書に載せる静的な画面イメージです。入力の保存・認証・送信・決済・金額計算・検索処理は実装していません。
入力内容を次のページへ引き継がず、固定の表示内容で画面遷移します。これらの説明は画面内には表示していません。
登録・変更と予約取消は指定の一覧／トップへ移動します。管理者の登録・変更・予約管理は独立ページとして作成し、遷移図の「戻る」で一覧へ戻れます。
ヘッダー・フッターの高さを変えた場合はstyle.cssのheader-frame・footer-frameも調整してください。

## 上映日の選択
ユーザー・管理者の上映スケジュール上部に10月2日～8日の日付選択を配置しています。選んだ日の一覧だけをHTML/CSSで切り替えます。予約画面にも同じ期間の日時候補を用意しています。日付・上映回を次画面に自動で引き継ぐ処理はありません。劇場名・スクリーン番号・座席図のSCREEN表記は全画面から取り除いています。

## 映画画像の選択
上映映画登録・上映映画変更に画像ファイル選択欄を追加しています。JPG・PNG・WebPを選択でき、ファイル名が表示されます。HTML/CSSのみのため、画像の保存・アップロード・一覧への反映・プレビューは行いません。

## 座席分析
分析一覧に全体予約率、エリア別空席構成比の円グラフ、列別予約率の棒グラフ、数値表を配置しています。既存のA～D列・各6席に合わせ、3上映回を集計した固定値（総72席、予約38席）で表現しています。空席構成比と予約率は異なる指標です。グラフはHTML/CSSのみで作成し、入力データから自動集計する処理はありません。
